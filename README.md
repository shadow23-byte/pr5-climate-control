# Практическая работа № 5 — Climate Control, вариант 3

Автор: Хусаинов Арсен Ильдарович.

В работе разобран риск подмены показаний климатического датчика и кратковременный отказ хранилища. Отчёт связывает сценарии с характеристиками качества ISO/IEC 25010, показывает реализацию HMAC-проверки и очереди повторной записи, таблицу испытаний, скриншоты Visual Studio и листинг программы.

## Содержимое репозитория

- `ПР5_Хусаинов_Арсен_Ильдарович.docx` — готовый отчёт Word.
- `ПР5_Вариант3_ClimateControl_проект.zip` — архив исходного проекта Visual Studio.

## Открытие отчёта

1. В списке файлов GitHub выберите `ПР5_Хусаинов_Арсен_Ильдарович.docx`.
2. Нажмите **Download raw file** или **Raw**.
3. Откройте документ в Microsoft Word. Во введении есть ссылка на этот репозиторий.

## Открытие и проверка проекта

1. В списке файлов выберите `ПР5_Вариант3_ClimateControl_проект.zip` и скачайте его кнопкой **Download raw file**.
2. Распакуйте архив. Внутри находится каталог `ClimateControlReliability` с файлами `.cs` и `.csproj`.
3. В Visual Studio откройте `ClimateControlReliability/ClimateControlReliability.csproj`.
4. Выполните **Сборка → Собрать решение**, затем **Отладка → Запуск без отладки** (Ctrl+F5).
5. Проверьте семь строк `PASS` и итог: `Итог: 7/7; сохранено: 2; отклонено: 3; в очереди: 0`.

Альтернативный запуск: в каталоге `ClimateControlReliability` выполните `dotnet run`. Нужен .NET 10 SDK. Очередь демонстрационная и хранится в памяти процесса.
